Flagship

CapacitiX

Competency development & learning management

Problem addressed: Skill development often splits assessment, learning and verification across separate tools. CapacitiX connects assessment, skill-gap analysis, personalized learning, practical tasks and trainer validation in one platform, so progress is measured and verified.

JavaSpring BootMySQLThymeleafAI integration
View Source Live Demo

Key features

  • Competency assessment and skill-gap analysis
  • Personalized learning path from identified gaps
  • Practical tasks reviewed by trainers
  • Trainer validation updates competency status
  • Reassessment to track improvement

Platform workflow

  1. Assessment
  2. Skill Gap Analysis
  3. Personalized Learning Path
  4. Practical Task
  5. Trainer Validation
  6. Competency Update
  7. Reassessment
Trainer validation keeps a human reviewer in the loop before competency is updated.

My role

Developer on the CapacitiX team. Contributions are listed in the repository and README.

Tech stack

  • Java and Spring Boot backend
  • MySQL for persistent data
  • Thymeleaf server-rendered interface
  • AI integration for the learning workflow

How AI is used

AI features support the learning workflow. Competency updates go through trainer validation, so AI output is reviewed by a person before it affects a learner's record.

Implementation highlights

  • Layered Spring Boot design: controllers, services, repositories
  • Relational schema for learners, assessments and competencies
  • End-to-end workflow from assessment to reassessment
