Flagship project

CapacitiX

AI-assisted competency development & learning management

Problem: Skill development is often split across separate tools for assessment, learning and verification, so it is hard to show whether a learner has really improved.

Solution: CapacitiX joins these steps in one platform. It identifies skill gaps, suggests a personalized learning path, assigns practical tasks, and relies on trainer review before a competency is updated.

Java 21Spring BootSpring MVCMySQLThymeleafAI-assisted

Key features

  • Personalized learning paths based on identified gaps
  • Practical task submission

AI in CapacitiX

AI features support the learning workflow. They do not replace assessment of competency: a trainer reviews practical work before a learner's competency is updated.

Why trainer review matters
A submitted practical task does not raise a learner's verified competency by itself. A trainer's approval is required first, so recorded progress reflects real, reviewed work.
