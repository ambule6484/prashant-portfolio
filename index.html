Featured Project

CapacitiX: Competency Development Platform

Flagship project

CapacitiX

Competency development & learning management

Problem: Skill development is often split across separate tools for assessment, learning and verification, so it is hard to show whether a learner has really improved.

Solution: CapacitiX joins these steps in one platform. It identifies skill gaps, suggests a personalized learning path, assigns practical tasks and relies on trainer review before a competency is updated.

JavaSpring BootMySQLThymeleafAI-assisted
View Source Code Live Demo GitHub Profile

Key features

  • Competency assessment and skill-gap analysis
  • Personalized learning path based on identified gaps
  • Practical tasks reviewed by trainers
  • Trainer review updates the competency record
  • Reassessment to track improvement

Platform workflow

  1. Assessment
  2. Skill Gap Analysis
  3. Personalized Learning Path
  4. Practical Task
  5. Trainer Review
  6. Competency Update
  7. Reassessment
A trainer reviews practical work before a competency is updated, so progress is verified by a person.

My contribution

CapacitiX was built as a team project. I am happy to walk through the modules I worked on and the design decisions behind them in an interview.

Architecture & stack

  • Java and Spring Boot backend
  • MySQL relational database
  • Thymeleaf server-rendered interface
  • Layered design: controllers, services, repositories

AI in CapacitiX

AI features support the learning workflow. They do not replace assessment of competency: a trainer reviews practical work before a learner's competency is updated.
